# homebrew-flute-cli-mcp

Homebrew tap for [flute-cli-mcp](https://github.com/getflute/flute-cli-mcp).
Formulae here are published automatically by cargo-dist on each release.

```sh
brew install getflute/flute-cli-mcp/flute-cli-mcp
```

`flute-cli-mcp` is an MCP server that drives the `flute` payments CLI, so it
also needs [flute-cli](https://github.com/getflute/flute-cli) **v1.1.0 or
newer** installed:

```sh
brew install getflute/flute-cli/flute-cli
```
